# MovieHub Backend

MovieHub is a scalable movie ticket booking backend built using Java Spring Boot.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- PostgreSQL
- Maven
- Swagger

## Modules

- Authentication
- Movies
- Theater Management
- Screens
- Seats
- Shows
- Booking
- Payment
- Admin Dashboard
